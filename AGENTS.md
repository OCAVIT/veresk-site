# AGENTS.md — правила для ИИ-агента в проекте VERESK

Этот файл агент читает первым (Claude Code, Codex, Cursor и другие). Здесь сказано, что за проект, где правда о
задаче, как работать и что уже сделано. Журнал шагов внизу агент ведёт сам: шаг записывается до работы и закрывается
после проверки и коммита.

## Проект

Одностраничный промо-сайт фолк-хоррора VERESK. Целевое действие одно — скачать именной билет на поезд до Вереска.
Статический сайт в папке `docs/`, хостинг — GitHub Pages.

## Как работать

1. **Маленькие шаги.** Один шаг — одна проверяемая вещь и один коммит. Шаг, который нельзя проверить за пару минут,
   делится на части.
2. **Сначала запись, потом работа.** Шаг заносится в журнал со статусом «в работе». После проверки статус меняется на
   «готово», рядом пишутся проверка и коммит.
3. **Проверять глазами.** Каждый визуальный шаг проверяется скриншотами десктопа (1440×900) и телефона (390×844):
   `python tools/shot.py <имя-шага>`. Скриншоты лежат в `process/screenshots/`.
4. **Ошибся — запиши.** Если проверка нашла ошибку агента, цикл «что сделал → как заметил → причина → исправление →
   правило на будущее» записывается в `Reflex.md`.
5. **Коммиты осмысленные.** На русском: что сделано и зачем. Одна тема — один коммит. Без строк о соавторстве ИИ.

## Правила дизайна (из скиллов)

- Палитра, шрифты и композиция — только из TZ.md, раздел 5.
- Над заголовками нет надзаголовков-«eyebrow». Мета-строки вида «A · B · C» не собираются.
- Нумерация только у последовательностей (главы).
- Нет градиентного текста, стекла с размытием ради красоты, одинаковых карточек и жёстких теней без размытия.
- Иконки — SVG одной толщины, не эмодзи.
- Движение одно: живой первый экран. Секции при прокрутке не «въезжают».
- Порог качества:
  - контраст текста не ниже 4,5:1;
  - фокус с клавиатуры виден;
  - нет горизонтальной прокрутки на 360–1920 px;
  - `prefers-reduced-motion` уважается;
  - выделение текста, каретка и полоса прокрутки оформлены в палитре.

## Технические правила

- Без фреймворков и сборки: `docs/index.html`, `docs/assets/style.css`, `docs/assets/night.js`,
  `docs/assets/ticket.js`.
- Локальный просмотр: `python -m http.server 8000 -d docs`, затем http://localhost:8000/
- Персональные данные никуда не отправляются: имя живёт только в браузере.
- Внешние ресурсы — только Google Fonts.
