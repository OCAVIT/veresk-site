# Reflex.md — где агент ошибся и как это исправили

Здесь записаны циклы «сделал → заметил ошибку → нашёл причину → исправил → проверил → правило на будущее». Правила
из последнего пункта перенесены в [AGENTS.md](AGENTS.md), чтобы агент не повторял ошибку.

## Цикл 1. Первый экран: элементы налезают друг на друга

**Что сделал агент.** Сцена за окном рисуется на canvas, поверх неё лежат HTML-элементы: логотип, «глаз» Смотрителя,
кнопка «Прикрыть фонарь», подсказка и билет. Положения луны, деревьев и Смотрителя агент задал долями ширины и высоты
окна, «на глаз», и закоммитил шаги 3–6 как готовые.

**Как заметили.** Первый же прогон `python tools/shot.py 01-first-build` показал четыре дефекта:

| Где | Что не так |
|---|---|
| Десктоп | Луна стоит ровно под «глазом» и выглядит как вторая сломанная иконка |
| Десктоп | Ближняя берёза проходит через буквы логотипа VERESK |
| Десктоп | Смотритель в лунном свете ярко-белый, его видно сразу, без фонаря. Руки сложены аркой и выглядят как медуза, а не как ветви |
| Телефон | «Глаз» накрывает подсказку «Ведите пальцем по окну — это фонарь», текст не читается |

До: [десктоп](process/screenshots/01-first-build-desktop.png),
[телефон](process/screenshots/01-first-build-mobile.png).

**Причина.**
- Агент считал раскладку сцены и раскладку интерфейса отдельно. Canvas ничего не знает о зонах, которые в CSS
  заняты логотипом, «глазом» и билетом.
- Мобильную версию до первого скриншота никто не смотрел.
- Шаги отмечены «готово» до проверки, хотя AGENTS.md требует сначала проверку, потом статус.

**Исправление** (коммит `ac51260`):
- **Луна:** на десктопе уведена в свободное небо справа (76 % ширины, 20 % высоты), на телефоне — под текст слева.
- **Берёза:** перенесена с 33,5 % на 44 % ширины, это правее логотипа.
- **Смотритель:** в лунном свете рисуется палитрой, утопленной в туман (`HIDDEN`), как дальняя берёза; выдают его только
  зелёные фонари, а ярким он становится под светом фонаря игрока. Руки теперь висят вдоль тела.
- **Подсказка на телефоне:** поднята над строкой с «глазом» и кнопкой.
- **Фон за заголовком:** добавлено тёмное пятно (`.window::before`), чтобы стволы за текстом не мешали читать.

После: [десктоп](process/screenshots/02-fix-overlaps-desktop.png),
[телефон](process/screenshots/02-fix-overlaps-mobile.png). Горизонтальной прокрутки нет на обеих ширинах, ошибок в
консоли нет.

**Правило на будущее.** Зоны интерфейса поверх canvas (заголовок, «глаз», билет) записываются вместе с раскладкой
сцены. После каждого визуального шага делаются скриншоты сразу десктопа и телефона. Статус «готово» ставится только
после скриншота.

## Цикл 2. Нарушение правил скилла в разметке глав

**Что сделал агент.** Над названием каждой главы поставил маленькую подпись «Глава I · вагон 6».

**Как заметили.** При самопроверке разметки по `craft-floor.md` до первого рендера.

**Причина.** Подпись над заголовком — это «eyebrow», а craft-floor запрещает его прямо: «a ban, not a default».
Строка, склеенная средними точками «A · B · C», — один из признаков ИИ-дизайна из скилла frontend-design. Агент
повторил привычный шаблон, не сверившись со списком запретов.

**Исправление.** Номер главы и место вынесены в левую колонку, на линию состава: римская цифра крупно, под ней «вагон 6»
или «412-й км». Номер здесь несёт информацию: главы — последовательность остановок вдоль поезда, от хвоста к
паровозу. Заголовок главы стоит сам по себе.

**Правило на будущее.** Перед версткой каждого раздела проверять: нет ли текста над заголовком, нет ли строк через
« · ».

## Цикл 3. Скилл скачался пустым

**Что сделал агент.** Скачал список справочных файлов скилла impeccable через GitHub API. Список имён сохранил из
Python в файл, потом в цикле bash скачивал каждый файл через curl.

**Как заметили.** Цикл напечатал `fail adapt.md`, `fail android.md` и так для всех 41 файла, а в папке `reference/`
оказался один файл.

**Причина.** Две ошибки подряд:
- В первой попытке путь `/tmp` у Git Bash и у Windows-Python указывал на разные папки, поэтому Python не нашёл файл.
- Во второй попытке Python на Windows записал список с переводами строк `\r\n`. Bash читал имя вместе с `\r`, URL
  заканчивался невидимым символом, и GitHub отвечал 404.

**Исправление.** Список кладётся в общую рабочую папку, а при чтении символ `\r` обрезается (`f=${f%$'\r'}`). Скачано
41 из 41 файла, 539 КБ. Проверено подсчётом файлов.

**Правило на будущее.**
- Между Python и bash на Windows передавать файлы только по общим путям и обрезать `\r`.
- После массовой загрузки сверять число файлов с ожидаемым, а не верить отсутствию ошибок.

## Цикл 4. Номер поезда читался неправильно

**Что сделал агент.** Напечатал на билете номер поезда «013Ч» точечным шрифтом кассы.

**Как заметили.** На первом билете, скачанном проверочным скриптом `tools/check_ticket.py`, при грубой точечной
сетке «Ч» неотличима от «4», и номер читается как «0134».

**Исправление.** Номер поезда сменён на «013А» (коммит `2c01083`), буква «А» в точечной печати читается однозначно.
Билет после исправления: [`03-ticket-anna.png`](process/screenshots/03-ticket-anna.png).

**Правило на будущее.** Тексты, которые печатаются точками, проверять на скачанном файле в реальном размере, а не в
исходной строке.
